# Etapa 06 — Solicitação e avaliação de exames

O atendimento começa com a escolha do fluxo. O motivo de rotina, o pedido profissional, a solicitação de avaliação médica e as condutas dependem de registro explícito. O formulário distingue os exames mencionados pelo paciente dos efetivamente solicitados. Na avaliação, os resultados e os achados transcritos têm campos próprios.

Alternar entre os modos conserva o motivo, as orientações, o encaminhamento, as condutas e a edição manual de cada fluxo durante a sessão. Os testes usam dados fictícios e cobrem início vazio, registro parcial, ausência de encaminhamento, ausência de condutas, recuperação após navegação e independência entre as evoluções.

Para reproduzir, execute npm test e npm run check na raiz. Execute os ensaios tests/lab-browser.cjs, tests/mobile-browser.cjs e tests/theme-browser.cjs no ambiente descrito na Etapa 01.
